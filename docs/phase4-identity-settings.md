# 第四阶段：应用隔离与配置中心

本阶段落实应用身份与可视化配置。统一任务中心、数据库、打印和业务导入导出留在后续阶段，不属于本次实现。

## 发布身份

```json
{
  "appId": "warehouse",
  "pageMode": "builtin",
  "url": "/",
  "desktopCapabilities": ["settings", "files"]
}
```

`appId` 为 1–48 位小写字母、数字或连字符，以字母开头。发布时写在 EXE 同目录的 settings.json，或用 HYBRID_APP_ID 指定。若使用 HYBRID_SETTINGS 指定配置，它也可用来引导身份。身份优先级为 HYBRID_APP_ID、协议启动携带的固定 --hybrid-app-id 参数、显式配置或部署配置。环境身份与文件显式身份冲突时启动报错，不切换数据目录继续运行。自定义协议注册命令会携带身份参数，系统从零启动应用时也能选回正确的用户配置。

启动先确定身份，再查找该身份专属用户配置，避免不同 EXE 都读取同一份旧用户设置。配置优先级仍是显式 HYBRID_SETTINGS、当前应用的用户目录、EXE 同目录、开发项目。运行中固定读写本次启动选中的文件，其他配置后来出现不会改变保存目标。

| 项目 | 默认身份 hybrid-infra | 自定义身份 warehouse |
| --- | --- | --- |
| 数据目录 | 用户配置目录/hybrid-infra | 用户配置目录/hybrid-infra/apps/warehouse |
| 系统协议 | hybrid-infra:// | hybrid-warehouse:// |
| 单实例 | 保留旧实例键规则 | 按身份和数据目录生成实例键 |
| 数据、窗口状态、备份、缓存文件 | 原目录继续使用 | 使用独立应用目录 |
| 系统凭据 | 原命名空间兼容 | 由独立目录及网页来源派生命名空间 |

HYBRID_DATA_DIR 仍可覆盖目录，它是精确目录，不会再追加 appId；部署多个业务应使用不同目录。故意指向同一目录时不承诺数据隔离，数据独占锁会阻止并发写入。内存事件和缓存随各自进程隔离。

身份确定后不可通过 SaveSettings 改名；否则旧进程仍握着旧数据，而重启会转向另一个目录。换 appId 属于发布新应用，现有数据不自动迁移。系统协议仅在明确调用 ConfigureProtocol 时注册或移除，不在启动时修改注册表；应用只接受自己的协议链接。更新重启保留身份和固定配置路径。

## 配置中心

地址 `/shell/settings.html`，工作台和托盘均有「配置中心」。需要 settings 授权；没有授权时页面显示说明并禁用表单，不自动提升权限。选择本地网页目录另外需要 files，也可手动填写路径。

- 展示应用身份、配置来源、读写文件、运行数据目录和专用协议。
- 页面模式支持 builtin/http/local，local 可选择目录。
- 可设置名称、窗口尺寸、最小尺寸、加载超时、启动屏、托盘、单实例、无边框、调试快捷键、外链行为。
- 勾选 desktopCapabilities，按来源编辑 permissions；空来源权限列表表示显式拒绝全部，不回退默认。
- 编辑允许来源、导航来源、Shell 程序白名单和 PNG 图标。
- 未显示字段通过完整配置草稿保留；高级 JSON 可修改更新源等字段，不允许改身份。
- 保存前展示 JSON 和未保存字段，保存后显示 pendingFields 和需要重启的状态；不会自动重启应用或立即变更权限。

GetSettings 返回 active/saved/preferences/restartRequired，以及 configPath/configSource/dataDir/appId/protocolScheme/pendingFields。无自定义配置时，首次保存写入当前应用用户目录。磁盘文件无效、被删除或身份不匹配时明确报错。

目录选择得到的文件 token 在填入路径后释放。配置中心保存的是网页根目录配置，不代表绕过文件服务的用户授权。F12 仍受 debug 和构建是否包含 devtools 共同影响。

## 验证

身份测试覆盖旧目录兼容、独立目录、身份与用户配置冲突、环境覆盖；宿主测试覆盖固定保存路径、拒绝运行中改身份、待重启字段和专属协议路由。前端测试覆盖表单合并、隐藏配置保留、显式拒绝权限、来源与数字验证。生成器同步主 SDK 和本地演示 SDK。

Windows 原生验收使用两份隔离测试配置：不同身份的进程可同时运行，配置中心显示各自的数据目录与协议；在 A 保存标题后，B 的配置和运行状态不变。保存后显示待重启字段，重启回读验证持久化。未通过 UI 注册真实系统协议或修改真实应用权限；协议选择与路由由自动化测试覆盖。macOS/Linux 原生配置界面尚未验收。
